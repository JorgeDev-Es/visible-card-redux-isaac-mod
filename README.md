# Instant Fires and Poops (Repentogon) 

instant-fires-and-poops-isaac-mod is a mod for [_The Binding of Isaac: Repentance_](https://store.steampowered.com/app/1426300/The_Binding_of_Isaac_Repentance/), written in [TypeScript](https://www.typescriptlang.org/) using the [IsaacScript](https://isaacscript.github.io/) framework.

Mejora el rendimiento respecto a mods como Isaac: Reflourished, pues la función se ejecuta mediante el callback de Repentogon en lugar de usar un update cada frame.
